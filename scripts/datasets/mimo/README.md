# Retain and upload the original MiMo sources

`prepare.py --root <directory> --inventory <reviewed inventory JSON>` captures the pinned Xiaomi MiMo V2.6 RL Parquet files, verifies their hashes and row counts against the reviewed source inventory, and prepares task prompts. It requires Python with PyArrow installed.

`pnpm exec tsx scripts/datasets/mimo/upload.ts --root <directory> --home <OpenPond home> --team <workspace id>` builds retained workspaces. Add `--apply --account <saved account handle> --api-base-url <API origin>` to upload them using an explicitly selected saved account. The account handle and API origin are checked before any write. Retained bytes and operation IDs are reused for retries; receipts verify the saved content hashes and task counts.

These are source drafts. The original Parquet files remain privileged, and visible task inputs contain the original prompts. Reviewed data-only publication does not require graders. Scored execution still requires the native environment adapters, private grader dependencies, source reviews, and runtime qualification. General also needs its separate upstream environment assets. These scripts do not substitute a synthetic scorer or mark those requirements complete.

Code environment qualification must also address the [Vals AI audit of October 7, 2026](https://www.vals.ai/blogs/mimo-reward-hacking): reference solutions can survive as unreachable Git objects, and solution-specific modification times can reveal patch scope. Build agent-visible environments from the pinned base source, exclude future Git objects and solution artifacts, normalize file timestamps, isolate hidden tests, and verify the resulting image rather than relying only on command restrictions. Preserve the original source snapshot separately for provenance.

`clean-code.py --root <directory>` writes a plan for all 2,698 Code tasks, using the original source hashes and a pinned, independently sourced image digest lock. Add `--task <id> --apply` to rebuild one image from its baseline checkout, flatten away upstream layers, remove Git history and known cache/solution residues, normalize timestamps, and run tasks as an unprivileged user. Repeated calls verify and reuse the retained image receipt. This runs locally with Docker; its image size and free-space checks deliberately stop unsuitable jobs.

Add `--qualify --reference-commit <full source fix commit>` for a single reviewed task to run both the unchanged baseline and the trusted reference patch against its original private test patch and command. Each run uses a fresh offline container. Scored runtime qualification requires baseline reward 0, reference reward 1, and independent residual-artifact review. A rebuild receipt alone does not establish safe or correct grading. Reference patches and qualification logs stay in the private cleanup directory, outside prepared task inputs.

Keep verified source files, prepared prompts, and workspace payloads under a retained directory that you supply as `--root`. Keep the saved account in the local `--home`. Upload receipts are written to `workspaces/upload-receipts.json`; retain them with the source inventory and original file hashes. Run cleanup and private qualification on an appropriate execution host, separate from archival storage.

`package-code-runtime.py --root <local retained directory> --output <taskset runtime directory>` packages one native Code runtime for the existing `portable-jsonl-stateful-v1` adapter. All 2,698 original task IDs resolve through the same hash-pinned bridge and mandatory pre-agent cleanup. `graders/managed-rl-runtime.json` declares the bridge; its pinned module also verifies every helper and source dependency. The environment declares the `terminal` tool. This runtime package is retained separately from the production source drafts until its execution assets and qualification are bound into a release.

On first use, the shared setup pulls only the selected digest-pinned image, captures its tracked baseline, replaces the entire original checkout and Git store, removes known cache/solution residue, normalizes timestamps, and verifies that only the fresh baseline remains reachable. Cleanup failure prevents the init response and any policy call. A private local cache is created before agent access and bound to the full image digest, cleanup code hash, repository path, and admission receipt. Repeated attempts use fresh containers from that cache. These internal images retain underlying upstream layers and must remain private; flattened, separately audited images are required for image redistribution.

Every agent command runs as UID 65532 with no capabilities and no network, with bounded time and output. Agent state is collected as a bounded repository patch; its container and background processes are destroyed before grading. A separate fresh environment applies that candidate, restores protected paths, and applies the original private test patch and command. Setup, collection and grading infrastructure failures are unscorable. Native execution prepares only the selected source image. Retain source and qualification evidence separately from agent-visible inputs.

`verify-code-runtime.py --root <directory> --task <id> --reference-patch <reviewed private patch>` exercises the packaged JSONL bridge, checks the admitted agent UID/capabilities, and runs both unchanged and reference candidates through separate fresh native graders. Retain the qualification receipt with the reviewed task. A representative pass qualifies that path; it does not qualify every source image or establish residual-artifact safety.

Before public distribution, independently review source rows, licensing, private-context references, and secret redaction. Preserve pinned originals and record the exact reviewed output and transformations. Public data distribution does not imply native scoring readiness.
