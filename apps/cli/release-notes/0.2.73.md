# OpenPond CLI 0.2.73

`training hosted-start` accepts `--estimate-review-file` with a complete hosted estimate receipt or its signed review object. Complete estimates are checked against the preparation’s workspace, plan ID, hash and revision before the signed review is forwarded through the existing SDK.

The server continues to verify the review’s binding, expiry and current pricing. The preparation cap, usage-quote hash, account authentication, `--yes` confirmation and chat attachment flow remain unchanged.
