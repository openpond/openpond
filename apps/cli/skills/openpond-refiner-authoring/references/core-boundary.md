# Refiner Core boundary

The Refiner Core defines evidence admission, structured decisions, privacy, ownership routing, deterministic validation, and immutable activation. A Review Profile is composed after that Core and cannot override it.

Harness and Refiner releases are adjacent identities. A Work turn pins both. The Refiner may propose a new Harness release; a later authoring turn may create a new Refiner release. Never let the acting release mutate its own definition during the same review.
