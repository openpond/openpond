# SDK 0.12.19

Experiment drafts retain selected continual-learning graders and an optional future adapter mode: Shared (`shared`), Stacked (`residual_append`) or Merged (`sequential_merge`). The mode reaches the existing saved Model configuration for RL updates independently of the current run's parent. Saving it on a fresh base does not enable a schedule or create a parent checkpoint.

Training operation labels are now SFT and RL. Omitted fields remain compatible, and native Job submission fields and worker algorithms are unchanged. Ponder 0.12.19 distributes this exact SDK version. CLI and Desktop versions are unchanged.
