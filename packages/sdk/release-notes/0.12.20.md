# OpenPond SDK and Ponder 0.12.20

Managed SFT authoring accepts up to 20 epochs and 400 optimizer updates. New image-specific capability schemas and recipe checks describe the exact immutable worker image, model/tokenizer pins, adapter ranks, sequence length and execution limits. Existing workers retain their reviewed limits; the authoring ceiling does not qualify a new runtime.

The training capability response now accepts the optional `supervisedTraining` image envelopes. Ponder exposes the same contracts through its exact SDK dependency.
